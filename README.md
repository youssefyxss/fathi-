# YouTube Video Processing Backend

## Overview
This is a Node.js Express.js backend that processes YouTube videos based on client configurations. It uses `ytdlp-nodejs` to download and process videos.

## Features
- Receive YouTube video links and configurations via API.
- Process videos based on client configurations (format, quality, output path).
- Return the processed video or relevant output.

### Prerequisites
